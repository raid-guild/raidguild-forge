# RaidGuild Forge Agent Guide

RaidGuild Forge closed in November 2026. This repo only deploys the redirects in
`next.config.ts` (see `README.md`); the full site is in the git history.

- Keep the `/subscribe/unsubscribe` redirect, with its query string, for as
  long as forge.raidguild.org resolves. Old Forge emails link there.
- Don't add pages, API routes or environment variables.
